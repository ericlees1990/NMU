**硬性规则**
1. 不得改图标几何、间隙与笔画比例。  
2. 英文锁两行：`NEW MATERIALS` / `UNION`（无斜杠）。  
3. Logo 填色仅限黑或白；辅色 `#1E3A5F` 只用于点缀。  
4. 保持安全区；勿旋转、拉伸、描边、投影。  
5. **不要另做第二套 Logo。**
