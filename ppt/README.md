## 中文说明

### 这是什么
面向对外演示的 **Blueprint Ink** 母版包：封面、章节、引言、指标、图表、流程与收尾，共 30 页。文案与数字均为模板样例，替换后使用。

### 快速开始
1. **可编辑母版：** [`NMU_PPT_Template_BlueprintInk_v1.pptx`](NMU_PPT_Template_BlueprintInk_v1.pptx)  
   用 PowerPoint、Keynote 或 LibreOffice 打开，复制页面并替换样例文案。
2. **浏览器对照：** [`NMU_PPT_Template_BlueprintInk_v1.html`](NMU_PPT_Template_BlueprintInk_v1.html)  
   方向键 / 空格翻页，`F` 全屏，地址栏 `#页码` 直达（如 `#12`）。

### 版式目录
| 页 | 版式 |
|----|------|
| 01–04 | 封面：品牌发布、章节开场、纯文字、深色变体 |
| 05 | 议程 |
| 06–08 | 章节分隔（居中编号 / 右侧重编号 / 顶栏同行编号） |
| 09–12、16 | 引言与强调（含唯一浅底反转，第 11 页） |
| 13–15 | 关键数字、前后对比、进度 |
| 17–22 | 柱状图、折线图、排名、环图、漏斗、散点 |
| 23 | 表格 |
| 24–26 | 横向流程、中心辐射、纵向流程 |
| 27–29 | 收束、致谢、联系 |
| 30 | 附录分隔 |

### 使用规则
- Logo 几何与填色以品牌 VI 为准：仅黑 / 白。本包内嵌的是幻灯片用法副本。  
- 母版文件仍在 [`png/`](../png) 与 [`svg/`](../svg)，**不要改那些原件**。  
- 辅色 `#3B82F6` 只用于弧线、分隔线与图表序列。  
- `hello@nmu.example` 与样例指标（如 98%、3.2×）不是正式数据。
