## 2. 方案 A · 已锁定 Logo（唯一主视觉）

### 2.1 图形标（Mark）

- 几何块面：左侧竖块 + **X / AI** 对角切分；统一线宽、45°/正交、负形缝等宽  
- **成套用法**（同一几何，只反色）：白底黑标 + 黑底白标  
- 横排锁与图标单独使用 = 用法变体，**不是两套方案**  
- 注意与 xAI 几何合字概念接近，应用时勿再改切分方式  

### 2.2 字标（Wordmark）

- 两行英文（**无斜杠**）：`NEW MATERIALS` / `UNION`  
- 不用 `XINCAILIAN` 作主英文  
- 中文「新材联」仅可选副行  

### 2.3 横排锁（Lockup）

左图标、右两行字；图标高度接近字高；间距约一个字母宽；垂直居中。
