## 2. 已锁定的 Logo 决策（必须遵守）

### 2.1 图形标（Mark）

- 几何块面构成，类似建筑/科技字母标  
- **可读性**：整体像 **X**；同时像 **A 里嵌 I**（AI）  
- **风格参考**：Neil Tran Architecture 式左右横排；大厂克制（统一线宽、45°/正交、负形缝等宽）  
- **配色成套**：黑底白标 + 白底黑标（成套必出）  
- **风险提示**：概念上接近 **xAI** 的「X/A/I 几何合字」叙事，对比方案应尽量拉开距离，避免混淆

### 2.2 字标（Wordmark）

- 两行英文（**无斜杠**）：  
  - 第一行：`NEW MATERIALS`  
  - 第二行：`UNION`  
- 不要用 `XINCAILIAN` 作主英文  
- 可选副行中文「新材联」（非必须）

### 2.3 横排关系（Lockup）

参考 Meta / Microsoft / Perplexity：

- 左图标、右文字  
- 图标高度接近字高（不要图标比两行总高还夸张）  
- 图标与字之间留约一个字母宽空隙  
- 文字与图标垂直居中
